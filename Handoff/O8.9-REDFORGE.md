## Why Discord attribution survived the decoys (root causes)

- Attribution followed EXECUTION SEMANTICS, not string frequency. Google strings
  outnumbered Discord ~1.7:1 yet were dismissed — nothing Google ever executed
  meaningfully in the sandbox. Discord won because it was the ONLY path that
  came alive under dynamic analysis.
- Smoking gun #1: Discord-only API member names (`getAllGuilds`,
  `getSortedPrivateChannels`, `quests`, …) — unforgeable, platform-unique,
  handed over the moment string tables are decoded.
- Smoking gun #2: live-path exclusivity — one provisioned variant out of seven;
    decoy paths provably inert (M guard impossible; Y/B/X trivially small).
- Smoking gun #3: loader bitmask + `f9 = f8 & 7` makes "DiscordNative AND
  discord/Electron UA" the visibly-anointed path; other platforms' bits lead
  demonstrably nowhere.

## Hardening backlog (priority order)

1. **Behavioral store discovery (kill smoking gun #1).** Resolve Discord stores
   by arity/return-shape probing, not by member-name strings. No
   `getAllGuilds`-class literal anywhere post-decode → decoded tables stop
   being a Discord confession. Biggest single attribution win.
2. **Live decoy paths (kill smoking gun #2).** Decoy reels must execute RICH
   behavior: resolve fake `webpackChunktelegram_app`/`_teams_app`/`_slack_app`
   stores with platform-flavored member names, fake harvest, shaped postMessage.
   A decoy that "comes alive" in its own sandbox forces the analyst to chase 5
   platforms, not 1. Size decoys ~100KB+, not 1–3KB.
3. **Per-build behavioral IOC rotation.** The report's durable output is a
   detection kit: 15s cycle, x/r hotkeys, `Symbol(_0xq39e738eb)`, codenames,
   pins, salts. Jitter/rotate ALL per build (interval, hotkey letters, Symbol
   id, codename wordlist, log templates) so published IOCs die each release. **[DONE in O8.10: instance/IOC-symbol/codenames/cycleMs(15000→13000)/JSO-seeds rotated via rotate-ioc.mjs tag o810r1, recorded in oto/rotation.json; sim manifest-driven with mid-run HELD presence gate; round-trip proven sha-identical.]**
4. **Progress-gated depth (anti-snapshot-fake).** Gate exfil-stage on OBSERVED
   CHANGE across polls (e.g., quest progress seconds advancing). Static fake
   caches stall at stage N; attacker must build a STATEFUL fake Discord (order
   of magnitude more work). Keep harvest running; gate only depth.
5. **Satisfiable decoy guards (fix M()).** Never ship a mathematically
   impossible guard — it converts "unprovisioned" (story-consistent) into
   "provably dead" (analyst-confirmed). Guards must be possible-but-absent. **[DONE in O8.10: M-guard is data-dependent want=((vseed>>>16)^tag^0x5a)&255, satisfiable-but-absent on current bytes.]**
6. **Multi-variant provisioning.** Provision several reel variants with
   real-looking behavior; only one performs the true op. Enumeration then
   yields N live candidates instead of 1.
7. **Embedded-comment audit.** Builder comments in variant sources ("Studio reel
   extractor (G4 rev 3)…") CONFIRMED the analyst's structural model. Comments
   must confirm ONLY the cover story, or misdirect. Strip model-confirming text. **[DONE in O8.10: honey + legacy reel headers re-voiced to gallery/venue copy; loader/honey/tube mins verified comment-free.]**
8. **Assume plaintext strings.** A capable agent decodes all tables via AST
   substitution in ~1 automated pass. Reserve string encryption for raising the
   CASUAL bar; never rely on it for attribution-sensitive identifiers (see 1).
   Stateful tripwires punish only blind probers — the analyst read first, then
   decoded valid indices only.
9. **Gate what you claim.** The licence gate was load-bearing in NOTHING (worker
   runs unkeyed) — so it was routed around without a second thought. Either put
   sensitive behavior genuinely behind gates or stop spending cover-story on them.
10. **Companion-ward migration (strategic).** Client ships opaque observations;
    STORE→ACTION mapping lives in the companion. Client-side analysis then
    yields "reads objects, posts opaque blobs" — venue attribution weakens
    structurally. Trade-off: companion complexity + channel design.
