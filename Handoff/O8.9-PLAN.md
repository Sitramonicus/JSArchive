### 3c. Trap architecture (detector + diverter + tube)
- Clean path: legitimate use pays ~nothing, never diverges. PRIMARY requirement.
- Deviation → tube: hooking, patching, stepping, instrumenting, tracing,
  input-enumeration. Brute-forcing trips it too — punished as a STRATEGY, not taxed.
- Divergence GRADUAL, never a branch: no `if (tampered) goto MAZE` (a static reader
  patches one branch). Defense = MANY subtle trip conditions, INTERLEAVED with real
  logic, so avoiding/patching all of them is expensive and error-prone. Static-only
  readers never trip anything — accepted; the trap targets dynamic-first analysts.
- Inside the tube: RE-PRESENTING mirrors (same mirror rendered fresh per visit from a
  per-visit nonce: names, constant spellings, op order, dead-code dressing — same
  semantics, unrecognisable surface; erasure must run DURING traversal, ocmY's
  after-the-fact erasure failed exactly here) + FAKE CONVERGENCE (breadcrumbs reading
  as partial results — adversarial narrative: "ah, this is the right path") +
  perceived depth/volume ("100 layers deep", actually a tube).
- Termination: "endless" is PERCEIVED, NEVER ACTUAL. The tube ALWAYS terminates —
  long, variable, unpredictable — returning plausible garbage. A catchable-by-users
  endless loop is a self-DoS; this is non-negotiable.
- Honest ceilings (measured, other session — artifacts NOT in this workspace):
  differential evaluation collapses N surface forms to 1 behaviour (volume taxes
  READING, not IDENTIFYING — structural invariant); AST-normalised similarity ~0.43
  vs ~0.098 raw; small constants leak (25/5-class tells; 32-bit spellings hold at 0/N);
  dressing ~9.4x real work — acceptable ONLY because legitimate users never enter the
  tube (cost asymmetry IS the design: user ~0, decoder unbounded).
- Heterogeneity lives in the OP VOCABULARY + SCHEDULE SHAPE, never in per-mirror code:
  per-mirror functions would reopen D1, and "one hook script doesn't fit all" is moot
  with nothing to hook. Volume lives in CAMOUFLAGE (analyst-paid), never in any
  legitimate-path cost.
- Metrics (ms/call, KB, guess-cost RETIRED for the trap): FP rate on legitimate use
  (GO/NO-GO, measured FIRST, before tube build-out); presentations per mirror; revisit
  recognisability (raw + AST-normalised); analyst context cost per traversal; progress
  illusion.
