# captures — what goes here

Drop the `__GDBG.report()` output from each pass as `capture-<YYYY-MM-DD>-pass<N>.md`.
A ctxt.io link in chat works just as well — whatever is easier.

What I look for, every time: the guard verdict at boot · the step1→step4 walk trace · the hooks row ·
one `entry(pwd…) … settled:` receipt · the ledger movement. Everything else is context.
