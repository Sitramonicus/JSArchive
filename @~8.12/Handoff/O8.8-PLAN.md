# O8.8 Plan — venue dead-ends (flat "8.8" generation)

## Why
AI#3 decoded `venueBits()` trivially (charCode names) and showed the fork plainly:
Discord/Electron venue → real payload, plain browser → garden decoy. Correct — but
now the whole narrative points at one platform (bad-press inference: "Discord
stealer"). 8.8 dilutes attribution by adding **dead-end venue narratives**: real,
verifiable API/host markers of other social platforms, each with its own
"provisioned board reel" branch that always fails closed to the garden.

## Design (loader-side; bundle quest logic untouched)
- Keep working trio EXACTLY: bit1 feed-array, bit2 `DiscordNative`, bit4
  discord-host/electron-UA/`Discord`-UA. Only low-3 `7` decrypts (unchanged).
- KDF mask (load-bearing): `vbits = venueBits(); bits = vbits & 7;` — seed, reel
  gate, and `tryLegacyReel(..., bits, ...)` (KG input) all use masked `bits`.
  Dead probes can never perturb the real key, even if one fires in-venue.
- 4 dead venues → bits 8/16/32/64 (all REAL, verifiable surfaces; none present
  in the Discord-console venue):
  - bit8 Telegram: `window.Telegram.WebApp` or host `telegram.org` (charCodes)
  - bit16 Teams: `window.microsoftTeams` or host `teams.microsoft.com` (base64+atob)
  - bit32 Zoom: `window.ZoomMtg` or host `zoom.us` (charCodes)
  - bit64 Slack: host `slack.com` or UA `Slack` or `window.slack` (reversed literal)
- Dead branches: `tryBoardReel()` per venue — reads derived pixels, checks an
  unmatchable magic (`(m0 ^ m1 ^ tag) !== 0x100` always throws: a byte can never
  equal `0x100`), returns nothing. Attempted before the real reel, always falls
  through to garden. No RNG, no carrier bytes, deterministic.
- Loader banner → `Pixel Garden Player v3.2.0` (+ "multi-board venue reels" note).
  Garden payload stays v2.0 (untouched decoy). `__STEGO3_REEL__`/`__STEGO3_SNAPSHOT__`
  placeholders and `loadSnapshot`/`tryLegacyReel`/`personalize` unchanged.
- Bundle: brand bump ONLY (`SUITE_VERSION` `8.7-Stego-3` → `8.8` in shard-a) so
  runtime branding matches the running version (operator constraint). Full OTO +
  stitch cascade; quest logic identical.
