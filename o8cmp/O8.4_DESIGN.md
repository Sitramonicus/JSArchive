## Corrected design 1 — humanized delay (GoogleDelay split)

Current (O8.3 line 438): `base = d*1000 - ln(1-u)*300` (+hidden +2–6 s, 12% burst +1.8–4 s, ×heat). Serves BOTH human waits and server-compliance waits (429 retry_after, 5xx backoff).

Correction: split roles.

```js
// Human-paced wait: log-normal, median = target, bursty tails, clamped.
const _0xln = (ms) => {
  const u1 = Math.random() || 1e-9, u2 = Math.random() || 1e-9;
  const z = Math.sqrt(-2.0 * Math.log(u1)) * Math.cos(2.0 * Math.PI * u2); // Box-Muller
  return Math.min(Math.max(Math.exp(Math.log(ms) + z * 0.35), ms * 0.3), ms * 4.0);
};

let GoogleDelay = async (d = 1) => {
  if (document.hidden !== _0xlastHidden) { _0xlastHidden = document.hidden;
    Log.say("Blinds", document.hidden ? "Curtains drawn — taking the long hallway." : "Curtains open — back on the main road."); }
  let base = _0xln(d * 1000);
  if (document.hidden) base += Math.random() * 4000 + 2000;
  if (Math.random() < 0.12) base += 1800 + Math.random() * 2200;
  base *= _0xheat;
  // …existing chunked abort-aware sleep loop unchanged…
};

// Server-compliance wait: raw, un-jittered (429 retry_after / 5xx backoff).
const GoogleDelayRaw = async (ms) => {
  let remaining = Math.max(0, ms);
  while (remaining > 0 && !signal.aborted) {
    const chunk = Math.min(remaining, 5000);
    const start = Date.now();
    try { await sleep(chunk, signal); } catch (e) { if (e.name === 'AbortError') return; throw e; }
    remaining -= (Date.now() - start);
  }
};
```

Retry call sites (`GoogleCall` 429/5xx) switch to `GoogleDelayRaw`. Config diag label: `delayModel: "lognormal"`.

## Corrected design 2 — macro rest (between chores only)

```js

  if (_0xb.length === 0 && activeTasks.size === 0) return false; // never rest after idle
  _0xresting = true;
  Log.say("Siesta", "Resting the eyes — back on the trail shortly.");
  await GoogleDelayRaw(_0xrestMs());

// and inside the drain branch before declaring idle.
```

Properties: only fires while real work remains; cannot interrupt a task (call sites are between tasks); abort-aware; resets window after rest; budget/rest durations are pure functions → unit-testable.

## Corrected design 3 — opaque predicates (2–3 real sites)

Side-effect-free invariants at branch sites, e.g. handler selection:

```js
// invariant: a quest config has exactly one supported task type chosen here
const _0xph = (0x9 + 0x1) === 0xA;             // always true, reads as noise
```

Rules: predicate is a pure expression; both branches identical for the false case; no state mutation inside. Only placed where the surrounding logic is already reviewed.
