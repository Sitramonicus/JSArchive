## Changes

**Channel B (behavioral):**
1. **Humanized delay model — log-normal split.** `GoogleDelay(d)` now uses Box-Muller log-normal (`_0xln`, σ=0.35) around the target in *seconds*: median = target exactly, mean ≈ +6%, tails clamped [0.3×, 4×] (verified 50k-sample stats). Hidden-tab penalty (+2–6 s), 12% burst (+1.8–4 s), and heat multiplier unchanged. Config diag: `delayModel: "lognormal"`.
2. **Server-compliance waits separated (`GoogleDelayRaw`).** The 429 retry-after and 5xx backoff paths call raw ms waits — never humanized (a blanket conversion would violate retry-after and cause 429 loops). Unit-verified paths in `GoogleCall`.
3. **Macro rest cycles.** New session budget 35–50 min (randomized per run); when exceeded and work remains, one 12–20 min rest happens **between chores** only (`Siesta` log, `GoogleDelayRaw`), never mid-task, never after idle, abort-aware; window resets after rest. Does not fire in any harness run (budget ≫ test length).

**Channel A (static):**
4. **Output-only per-instance identifier rotation.** 8 neutral helper identifiers (`recordDelay`, `sanitizePath`, `extractHttpProgress`, `findTaskConfig`, `registerCleanup`, `activeTasks`, `sleep`, `maybeRest`) are renamed to fresh hex names per instance by the generator (word-boundary replace, validated 0 residual tokens). Google* codename/cheat-code layer untouched. This is the biggest cross-instance dissimilarity win to date — only strings/comments/diag stay stable across instances.
5. **Regex-noise.** The decode sanity regex is built at runtime from a char-code array (`_0xJRe`) — no plaintext pattern literal in the file.
6. **Equal-effect opaque predicate.** `_0xroute0` selection now passes through `((1/3)*3)===1 ? location.pathname : location.pathname.slice(0)` — both arms identical in effect, so even if a deobfuscator "drops" or flips the predicate, semantics cannot change (this is the Drop-resistant design; see `O8.4_DESIGN.md`).
