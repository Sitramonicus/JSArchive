## Changes (all single-subsystem deltas on the J-7 base)

1. **Queue refill on finish (user's O8.3 feature).** The work loop now re-reads the quest store whenever the queue drains (`_0xrefill`), appending eligible stragglers (not enrolled/completed/expired/unsupported, deduped by id via `_0xdone` set). Log: `[Google Ledger] N more chore(s) joined the board.` No new timers, no subscriptions — refill happens only at existing chore boundaries, per the user's design. In-flight tasks are never interrupted; a chore that was already processed is never re-added within a run.
2. **Timestamp monotonic log fix (colleague #6).** `monotonic` now compares against the previous value (`_0xmono`); verified `monotonic: true` appears live in harness output.
3. **Cleanup log order fix (colleague #7).** `finishTask()` now runs before the `activeTaskCount` diagnostic in both desktop and stream cleanup.
4. **Fail-closed URL guard (colleague #5; user chose fail-closed).** `GoogleId` now unwraps nested shapes (`application.id`, `quest.id`, `guildId`, `activityId`), returns `null` when unresolvable; route builders return `null`; `GoogleCall` rejects non-relative/empty/garbage URLs with a warning and skips the request (`{ body: {}, skipped: true }`) instead of coercing to `""`/`[object Object]`.
5. **Generator fixes.** Decoy opaque guard is now genuinely never-true (`(0.1+0.2) === 0.3` — the `(1<<32)===1` guard was true in JS and executed a benign pure function); encoder asserts every plaintext fits the sanity charset at build time.
